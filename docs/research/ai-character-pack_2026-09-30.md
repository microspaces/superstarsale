## 1. The character

| Field | Value |
|---|---|
| Name | **Sal** (no surname — keeps it mascot-like, avoids real-person collisions) |
| Age / look | 63. Silver hair, neat grey beard, reading glasses pushed up on forehead, flannel or cardigan over a plain tee. Warm, tired-hands, workshop-shelf background. |
| Backstory | Ran a print shop for 31 years. Retired, got bored in 4 months, now teaches the boring files that kept his shop alive. Never claims riches — claims survival. |
| USP | The anti-guru: no course, no Lambo, no "passive income" — a retired shop owner handing you the paperwork habits that kept a real business open for three decades. |
| Voice rules | Short sentences. Plain words. Zero hype vocabulary ("passive income", "financial freedom", "crushing it" are banned). One dry dad-joke per reel, max. Numbers only with a real receipt on screen (kit §6). |
| Catchphrase | **"Boring pays."** — close-line on the strongest reels, not every reel. |
| Disclosure | Bio line (below) + never implies he's a real human. Replies written as the club, not as Sal pretending to have lived today. |

**Consistency sheet for image generation** (tool-agnostic — works with whatever the local workflow uses; replaces the video's Higsfield steps 4/6):
- Prompt block — full body: `Full-body character sheet of "Sal", a 63-year-old retired print-shop owner, silver hair, neat grey beard, reading glasses on forehead, worn flannel shirt over plain tee, jeans, work boots, standing relaxed with one hand in pocket, warm neutral studio background, realistic skin texture, soft daylight, photorealistic, 9:16.`
- Prompt block — close-up: `Head-and-shoulders portrait of the same man: 63, silver hair, neat grey beard, reading glasses on forehead, faint smile, kind tired eyes, realistic skin pores, soft window light, plain warm-grey background, photorealistic, square.`
- Lock these in every generation: same flannel color (dusty red), same glasses, same beard length. Location set (5 recurring scenes): home office desk · print-shop shelf wall · kitchen table with coffee · garage workbench · car (parked, mid-thought).

## 3. The ten reels, re-scripted in Sal's voice

Same Hook→Value→Tease→CTA skeleton, same CHECKLIST trigger, same bridge-page funnel. Angles tagged for the 3-angle test (§4). Production: 9:16 1080p, captions always, 15–35s, Sal VO over screen-record unless noted.

Angle mix: 4 pain / 3 contrarian / 2 proof / 1 intro-pin. If a reel hits, clone its format (kit rule), not its topic.

## 4. Portfolio test — adapted, one niche

- **Launch ONE account first** (@boringbusinessclub, Sal). Each extra account costs real Mike-steps (setup, posting, ManyChat) — the video's 3-account parallel bet only makes sense when content is the bottleneck. For us content is cheap; setup isn't.
- **The test runs INSIDE account one:** 3 hook angles (pain / contrarian / proof) across the first 10 posts, tracked per reel.
- **Decision rules:** judge at **post 10 AND day 14** (his own Vivian data: 7 days mis-ranks). Winner = saves+shares + CHECKLIST comments, NOT views. Losing angle drops from the calendar; winning angle doubles.
- **Variant specs (paper only until needed):** if day-14 data is ambiguous or a second account is cheap to run, spin variants of Sal — "Sal, evening version" (calmer, slower VO) and "Niece Jae, 29" (does the chores, Sal mentors) — same niche, same bridge page, same files. Never a second niche.
