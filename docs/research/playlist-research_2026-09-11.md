## The Best of the Batch

### nas.com — Nas Daily's AI-native commerce platform *(best receipts)*
Nas Daily demoing **his own product**: an AI-native Shopify competitor where the platform itself allocates ad budgets (live Meta spend-shifting, human-veto-only). Live dashboards shown: Mass House Dubai funnel $130 spend → 22 tickets ≈ $220. This is **AI-native commerce with autonomous ad allocation** — a step past known agentic-payments themes: the agent isn't buying *for* the human, it's reallocating the human's marketing budget autonomously. Worth Watching: if the AI-allocated-budget model holds at scale, "storefront + autonomous media buyer" collapses a $2-5K/mo agency line item.

### Resolve 21.1 MCP + Deepgram — agent video editing goes production-grade
Two independent videos converged on the same pipeline: desktop app exposes an MCP server → agent does skilled production labor (rough cut, graphics, export, self-QA). The unlock that makes it clean: **swap Resolve's dropped-word built-in transcript for Deepgram word-level JSON (~$20 credits)**. Real numbers: 23:58 raw → 7:14 base cut in under 20 min, $13–19/video standard ($30–40 fast mode) vs 3–4 manual hours. This is the first demonstrably production-grade agent-does-skilled-labor pipeline in the archive — and the direct blueprint for OpenMontage-adjacent work.

### Fable 5.1 one-job experiment — qualification-then-asset outbound
Agent read ~150 reviews × 20 Fresno paralegals, rejected 18/20 with reasoned walk-away rules, auto-built a private calculator report page per prospect, drafted outreach — **under $3 total API spend**, human keeps the send button. The new mechanic: the outreach hook is an *auto-built private asset* (calculator page), not a message. Asset-automation, not message-automation.

### Local AI on Strix Halo (~$4K) — privacy moat + cost arbitrage
llama.cpp + Vulkan + GPU clock override + MoE models = 100→688 prefill TPS; $300/mo cloud spend replaced; private financial/medical/client-data workloads become feasible *because* they're local — the privacy moat framing is the new part, not the speed.
